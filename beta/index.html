Download details

Details

RAPP Brainstem Frontier puts the live agent Explorer, the real Brainstem chat, and GitHub Copilot Brain Surgeon in one visible workspace. Describe the outcome you need, watch the capability get built or routed, run it through the same RAPP/1 chat wire, and keep the evidence and portable single-file agent.

Frontier composes global and routed agents into isolated hardlinked AGENTS_PATH workers without changing the Grail brainstem.py kernel. It reuses your local agents, soul, authentication, memories, and storage under ~/.brainstem.

Learn by watching

See files, tool calls, tests, screenshots, recordings, and corrections as the work happens.

Build through chat

Ask for an outcome instead of assembling a separate editor, terminal, and agent-development workflow.

Keep the capability

Promote a proven RAPP skill into Hippocampus, Copilot Studio, Foundry, or the right Microsoft host.

System Requirements

Supported operating systems

Windows 11 x64 macOS x64 or ARM64 Linux x64 or ARM64
  • A GitHub account with GitHub Copilot access. Brainstem handles GitHub sign-in and does not require a separate AI API key.
  • Internet access for the first installation, release verification, and GitHub Copilot token exchange.
  • Permission to install desktop applications and developer prerequisites on the device. Managed-device policy may block source-built previews.
  • Application signature and native installation verification are not claimed for this preview. This page checks release-manifest metadata, not the application signatures themselves. Windows Defender SmartScreen warnings may still appear for unsigned source-built previews. The bootstrap does not suppress or remove those warnings.
  • Synthetic or approved data only. This Frontier build is a rapid proof and teaching environment, not a production deployment.

Install Instructions

Use the selected source command to install, update or repair, and launch Frontier from the displayed release commit. The downloaded source command uses that same commit; it does not resolve “latest” again. A source recovery bootstrap instead checks the latest published brainstem-beta-v* release in this deployment's repository before running its installer.

PS Windows 11 x64

Open PowerShell, paste the command, and press Enter.

powershell -ExecutionPolicy Bypass -File ".\RAPP-Brainstem-Frontier-Windows.ps1"
Download bootstrap

>_ macOS or Linux

Open Terminal, paste the command, and press Enter.

bash "$HOME/Downloads/RAPP-Brainstem-Frontier-macOS-Linux.sh"
Download bootstrap
  1. Run the installer command for your operating system.
  2. Let the bootstrap install or reuse the shared Brainstem, then assemble the isolated Frontier launcher from the resolved release commit.
  3. Launch RAPP Brainstem Frontier from Applications, Launchpad, the Linux app menu, or the Windows Desktop or Start Menu.
  4. Complete GitHub sign-in when Brainstem prompts you.
