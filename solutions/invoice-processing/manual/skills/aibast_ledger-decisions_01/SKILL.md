# Ledger decisions

Use when someone asks which invoices would be logged, which are duplicates, which were only partly read, or what row would be added to the ledger.

## Procedure

1. Use only the uploaded synthetic records and rules.
2. Lead with the result table this skill returns.
3. Keep every record id, amount, date, and count exactly as recorded.
4. Explain what needs a qualified person's confirmation.
5. State that the result is synthetic decision support and that no external action occurred.
