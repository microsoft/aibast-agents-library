Troubleshooting

Copilot Studio says a skill file has invalid frontmatter

Download the raw file again and confirm the filename is exactly SKILL.md. Upload the file itself—not the containing folder or the .mcs.yml source component.

A knowledge file appears but is still processing

Wait for ingestion to finish before testing. Preview can return incomplete answers while a knowledge source is still being indexed.

The model picker does not show Claude Sonnet 4.6

Select an approved model available in your environment, then record the substitution. Easy and Hard mode should use the same model when you are comparing parity.

A Preview response misses a required identifier

Confirm both knowledge files are enabled, all four skills appear in the inventory, web search is removed, and the global instructions prohibit invented records. Start a fresh Preview conversation and replay the exact canonical prompt.
