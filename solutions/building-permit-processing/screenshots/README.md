# Copilot Studio deployment screenshots

This directory stores the real Copilot Studio walkthrough captured from the
validated pilot environment.

Required captures:

1. Agent overview and environment.
2. Settings, model, language, authentication, and global instructions.
3. Skills and tools created for the four permit workflows.
4. Connection references and connection health.
5. Preview with each canonical prompt.
6. Publish review screen before confirmation.

Screenshots must come from the actual deployed pilot. Do not substitute mockups.

Captured from the published kodyv8 pilot:

- `01-home.jpg` — target environment.
- `02-agent-list.jpg` — published agent listing.
- `03-build-overview.jpg` — instructions, model, skills, and knowledge.
- `04-skill-inventory.jpg` — expanded skill definitions.
- `05-preview-ready.jpg` — Preview before the customer prompt.
- `06-preview-result.jpg` — canonical backlog prompt and live response.
- `07-monitor.jpg` — monitoring surface.
- `08-publish.jpg` — explicit publish step.
- `copilot-assisted-walkthrough.gif` — animated Easy-mode deployment path.
- `copilot-assisted-contact-sheet.jpg` — static overview.

`browserfilm.json` is the reproducible frame manifest.
