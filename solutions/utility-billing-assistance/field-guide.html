Use this guide to understand the workshop boundary, expected proof, production seams, and recovery paths before or during the hands-on module.

Facilitator crash course: optional Brainstem track

Brainstem is the learner's local-first, inspectable agent runtime. GitHub Copilot remains the familiar work surface; Brainstem adds persistent local workshop context, hot-loaded Python agents, and a visible tool-calling loop. Core setup uses the learner's GitHub account with Copilot access and requires no separate model API key.

Canonical preparation source: this guide uses the Microsoft AIBAST Brainstem installer. The former upstream Grail installer is not used by this Microsoft/AIBAST workshop path.

Pre-work: participants install it themselves

macOS / Linux

curl -fsSL https://microsoft.github.io/aibast-agents-library/install.sh | bash

Windows PowerShell

irm https://microsoft.github.io/aibast-agents-library/install.ps1 | iex

The one-liner installs the runtime, starts Brainstem, opens GitHub authorization when needed, and opens http://localhost:7071. Participants do not run gh auth login or brainstem separately.

Before the session, verify:

curl -s localhost:7071/health | python3 -m json.tool

The facilitator completes setup first, then asks Brainstem-track participants to run the one-liner themselves before workshop day. Never collect participant GitHub tokens or run one shared installation on their behalf.

Run the built-in five-minute interview loop

Choose New here? Take the 5-minute guided tour in the Brainstem chat UI. Let participants click and type; do not turn the tour into a slide lecture.

  1. Interview: click What can you do? Treat the response as a resume, not proof.
  2. Teach: enter a non-sensitive preference such as Remember that I prefer concise answers. Watch the visible memory-agent decision.
  3. Reset: clear the conversation. Chat history is short-term context; approved memory persists locally.
  4. Verify: click What do you remember? Reinforce claim -> test -> verify.
  5. Inspect: open the agents panel. Every capability is a readable local *_agent.py file.
  6. Trade safely: when offered, export a removable agent, delete it, verify Brainstem reports the missing capability honestly, then drag the file back to hot-load it.
  7. Use the registry (optional): open the book panel, find @rapp/learn_new, and add it. Skip when unavailable.
  8. Create: ask it to create a small QuoteOfTheDay agent and confirm the file appears.
  9. Continue: click What should I do next? Summarize: interview, teach, correct, trade, create.
Safety: the tour skips export/delete/restore when no removable agent exists. Never delete memory agents or use customer, credential, health, financial, or other sensitive information in the memory demonstration.

The pilot must never claim a live lookup or external write unless an approved production tool returns evidence that it succeeded.

Evidence gates

  • Source: deployment source and isolated transcripts exist.
  • Local: every locked business-agent case passes.
  • Preview: every front-door case passes in a fresh chat.
  • Visual: only approved annotated checkpoints count as proof; review-required captures may appear only as clearly labeled orientation references.
  • Draft: the package records published: false.
  • Customer: governance, telemetry, support, and success measures are agreed before production.
