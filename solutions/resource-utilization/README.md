## Implemented scope

The package demonstrates utilization visibility, near-term capacity, bench
analysis, skill-and-level pipeline matching, and upskilling plus internal
innovation planning. All people, pipeline, probabilities, costs, and value
scenarios are fictional.

The agent recommends options only. It does not assign consultants, alter
employment records, book revenue, approve training, or contact anyone.
