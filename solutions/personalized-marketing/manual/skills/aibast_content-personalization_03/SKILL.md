# Consent-aware content personalization

Use for headline, CTA, category, or product-idea requests.

1. Ground the answer in the aggregate segment and packaged content blocks.
2. Label all language and recommendations as drafts.
3. Explain which non-sensitive aggregate signal supports each idea.
4. For VIPs show the three A/B variants (product, urgency, rewards) and the
   33/33/34 split over 12 hours; time-limited wording is a draft for approval.

Do not identify a person, infer a sensitive trait, send a message, create an
offer, issue a reward, or complete a purchase.
