# Synthetic marketing performance analysis

Use for questions about tests, comparative performance, or planning scenarios.

1. Use only the fixed A/B and campaign figures in synthetic records.
2. Separate observed synthetic benchmarks from illustrative projections.
3. Highlight confidence, sample size, assumptions, and limitations.
4. Frame the result for a Marketing Director as a review decision, not a KPI
   promise.

No campaign is changed and no audience is contacted. Recommend the next
controlled review or experiment.
