# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the existing
issues before filing new issues to avoid duplicates. For new issues, file your bug or
feature request as a new Issue.

Before submitting your issue please search the [issues](https://github.com/microsoft/aibast-agents-library/issues) to ensure your issue has not already been reported.

If your bug or feature request has already been reported, join the conversation by commenting and adding your reaction. Please use reactions to vote and not "+1" comments.

## Support for the AIBAST Agents Library

Although the underlying features and components used to build the AIBAST Agents Library are fully supported (such as Copilot Studio, Power Automate and Dataverse), the library itself represents an example implementation of these features. Our customers, partners, and community can use and customize these features to implement capabilities in their organizations.

The agents in this library should be seen as templates from which you inherit your individual solution, or as inspiration for implementing your own.

If you face issues with:

- **Using the AIBAST Agents Library**: Report your issue here https://github.com/microsoft/aibast-agents-library/issues. Microsoft Support won't help you with issues related to the library, but they will help with related, underlying platform and feature issues.
- **The core Microsoft features**: Use your standard channel to contact Microsoft Support: [Get Help + Support](https://learn.microsoft.com/en-us/power-platform/admin/get-help-support)

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
