## How It Works

The agent library is this repository; `registry.json` at the root lists every agent. CommunityRAPP's `AgentLibraryManager` agent reads that registry to let users browse, search, and install agents through the chat UI.

### Install an agent via chat:

```
User: "Show me available agents"
→ AgentLibraryManager fetches registry.json and lists the agents and stacks

User: "Install the account intelligence agent"
→ Downloads account_intelligence_agent.py from the library into agents/
→ Restart to load
```

### Direct download:

```
Registry: https://raw.githubusercontent.com/microsoft/aibast-agents-library/main/registry.json
Agent:    https://raw.githubusercontent.com/microsoft/aibast-agents-library/main/{_file from the registry}
```

## Agent Catalog

Individual agents and agent stacks (multi-agent compositions), listed in `registry.json`.

Agents are auto-discovered `*_agent.py` files that extend `BasicAgent` and implement `perform()`. Drop one in `agents/`, restart, and it's live.

---

## Agent Format

Every agent is a single `.py` file:

```python
from basic_agent import BasicAgent

class MyAgent(BasicAgent):
    def __init__(self):
        self.name = "MyAgent"
        self.metadata = {
            "name": self.name,
            "description": "What this agent does.",
            "parameters": {
                "type": "object",
                "properties": {
                    "input": {"type": "string", "description": "Input"}
                },
                "required": ["input"]
            }
        }
        super().__init__(self.name, self.metadata)

    def perform(self, **kwargs):
        return f"Result: {kwargs.get('input', '')}"
```
