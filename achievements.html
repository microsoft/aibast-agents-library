AGI means Agent Growth & Impact. It records workshop milestones on this browser and device; it is not an evaluation of agent capability or externally verified proof.

Local versus verified: local points are private, self-reported checkpoint progress. An earned badge remains Local unsynced until it appears in the accepted public metrics snapshot as Verified synced. No local progress is sent automatically.

Opt-in public verified AGI profiles

Public verified achievements come from submitted AGI progress issues, not from this browser's local score. Opening the prefilled form is not a sync until it is submitted. Resubmitting later merges newly earned canonical badge IDs without duplicate score; the server computes the verified score. One public GitHub issue submission opts that account into a public verified profile.
