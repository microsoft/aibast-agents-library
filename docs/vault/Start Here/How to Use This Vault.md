# How to Use This Vault

This **vault** is a set of linked notes.
It expands the RAPP production guide and the rapp/1 protocol into short, readable pages.
You can read it in your browser, or download it and open it in Obsidian.

## Reading in the browser

Each note is one page. Links between notes are underlined.

- **Search** — find any note by title or text.
- **Graph** — see how notes connect to each other.
- **Backlinks** — at the bottom of a note, see which other notes link to it.

### Keyboard keys

| Key | What it does |
|---|---|
| `j` / `k` | move to the next / previous note |
| `/` | open search |
| `g` then `g` | open the graph |
| `g` then `i` | go to the index |
| `r` | open a random note |
| `m` | turn reading mode on or off |
| `?` | show or hide the keyboard hint |

## Downloading the vault

You can take the whole vault with you as a real Obsidian vault.

1. Press the **Download vault** button at the top of the page.
2. You get `rapp1-vault.zip`.
3. Unzip it.
4. In Obsidian, choose **Open folder as vault** and pick the unzipped folder.

Every `[[wikilink]]` works in Obsidian, because each note file is named exactly after its title.

## How each note is built

- A short **plain-language lead** at the top.
- Sections with clear headings. Technical detail sits lower down.
- Exact identifiers stay in `code` style, for example `rapp/1`.
- A **Related** list at the end.

Each note's frontmatter names its source. See [[Sources and Provenance]].

## For AI tools

AI tools can read the vault directly:

- `llms.txt` — a short index of the notes.
- `llms-full.txt` — the full text of every note in one file.

The **Plain text** button at the top opens `llms-full.txt`.

Point an assistant at either file to ground its answers in this vault.
