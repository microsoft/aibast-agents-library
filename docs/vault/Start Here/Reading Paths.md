# Reading Paths

A **reading path** is a short, ordered list of notes for one role.
Pick the path that matches your job. Read top to bottom.
You can leave the path at any point and follow links.

## Pick your path

| You are | You want to | Path |
|---|---|---|
| **Business lead** | understand the process and what each step delivers | Business lead |
| **Builder** | write an agent and get it running | Builder |
| **Implementer** | build software that speaks rapp/1 | Implementer |

## Business lead

For people who sponsor, plan or review agent projects.
No code required.

1. [[Production Guide Overview]] — the 14 steps from discovery call to post-deployment review.
2. The steps, in order — start with [[Step 01 Discovery Call]] and continue through [[Step 14 Post-Deployment Review]].
3. [[Protocol at a Glance]] — a one-page view of what sits underneath.

## Builder

For people who write and ship agents.

1. [[The Agent Contract]] — what a single agent file must provide.
2. [[The Frame]] — how each event is recorded.
3. [[The Egg]] — how agents and rapplications are packaged to move between machines.
4. [[RAPP Deploy]] — how a release reaches users.

## Implementer

4. [[Identity and the Rappid]]
5. [[The Frame]]
