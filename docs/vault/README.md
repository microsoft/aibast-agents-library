# Welcome

**This vault is the reference half of the RAPP production guide.**
The [production guide](../rapp-guide.html) tells you what to do at each of the
14 steps. This vault tells you more about each step, and explains the
**RAPP/1 protocol** underneath it: how an agent is identified, recorded,
packaged and moved.

## Who it is for

- **Business leads** who run the 14-step process and want each step in depth.
- **Builders** who write and ship single-file agents.
- **Implementers** who want to read or write RAPP/1 records in another language.

[[Reading Paths]] gives each of them a route through the notes.

## What is inside

- **[[Production Guide Overview|Production Guide]]**: one note per guide step.
- **[[Protocol at a Glance|Protocol]]**: the RAPP/1 specification in plain language.
- **Operations**: release, deployment and work records in [[RAPP CICD]], [[RAPP Deploy]] and [[RAPP Work]].
- **Building**: the agent file in [[The Agent Contract]], the Brainstem in [[The Brainstem Kernel]], and pinning in [[Distros and Pinning]].
- **Reference**: terms in [[Glossary]], failures in [[Failure Atlas]], and sources in [[Sources and Provenance]].

## Ways to read it

- **In the browser:** search, backlinks and a graph of every link.
- **In Obsidian:** download the vault and open the folder. See [[How to Use This Vault]].
- **With an AI tool:** point it at `llms.txt` or `llms-full.txt` in this folder.

## Where the content comes from

Protocol notes restate the upstream RAPP/1 specification at a pinned commit.
See [[Sources and Provenance]] and the [Notice](NOTICE.md).
