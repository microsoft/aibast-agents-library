Write Your First Agent

Create a Python file in the agents folder. The brainstem picks it up automatically.

~/.brainstem/src/rapp_brainstem/agents/weather_agent.py
from agents.basic_agent import BasicAgent class WeatherAgent(BasicAgent): def __init__(self): self.name = "Weather" self.metadata = { "name": self.name, "description": "Get weather for a city.", "parameters": { "type": "object", "properties": { "city": {"type": "string", "description": "City name"} }, "required": ["city"] } } super().__init__(name=self.name, metadata=self.metadata) def perform(self, city="", **kwargs): return f"Weather in {city}: sunny"

That's it. Save the file. The brainstem discovers it. The AI can now use it. No restart needed.

This is the portable RAPP pattern used throughout the AIBAST Agents Library: one reviewed file, one focused agent contract.
5

Customize the Personality

Edit the soul file to give your AI a personality:

~/.brainstem/src/rapp_brainstem/soul.md

This markdown file is the AI's system prompt. Write who it should be; the Brainstem reloads it for every request and keeps your edits across restarts.

Long-term facts are handled separately by the bundled memory agents. The soul defines behavior; memory stores recalled context.
